# Хобі Хатка — матеріали для творчості

Навчальний багатосторінковий сайт інтернет-магазину товарів для хобі (фарби, пензлі, декор для діорам, бісер, натуральне каміння). Усе демонстраційне: платежі та відправлення замовлень не реалізовано.

**Live Demo:** https://hobby-house-nu.vercel.app/

## Сторінки
Головна · Каталог (фільтри, пошук, сортування, калькулятор замовлення) · Товар · Кошик · Оформлення · Підтвердження · Профіль · Про нас · Контакти (форма з валідацією RegExp).

## Технології
- HTML5, CSS3 (дизайн-токени, світла й темна тема), чистий JavaScript (без збірки й фреймворків)
- Tailwind CSS через CDN (сторінка контактів)
- Mock-дані: `data.json` (товари, відгуки), завантажуються через `fetch()` / `async`
- Бібліотеки через CDN: Swiper 11, Fancybox 5, Typed.js 2, AOS 2
- CI/CD: GitHub Actions (`.github/workflows/deploy.yml`) → Vercel
- Інструменти ШІ: Claude (розробка, тестування, документація)

## Основні функції
- Каталог із фільтрами за категорією, ціною та наявністю, пошуком і сортуванням
- Кошик у `localStorage`, оформлення замовлення з валідацією
- Калькулятор замовлення з захистом від некоректного введення (Edge Cases)
- Перемикач світлої/темної теми (збереження вибору в `localStorage`)
- Слайдер відгуків, галерея з лайтбоксом, анімації при скролі

## Структура
```
index.html … contacts.html   9 сторінок
styles.css, pages.css        стилі (токени, компоненти)
data.json                    mock-дані (товари, відгуки)
assets/js/site.js            меню, кошик, каталог, тема, завантаження data.json
assets/js/plugins.js         Swiper, Fancybox, Typed.js, AOS
assets/js/widget.js          калькулятор замовлення
assets/js/validation.js      валідація форми контактів
scripts/check-data.js        перевірка data.json (використовується в CI)
```

## Запуск
`data.json` завантажується через `fetch`, тому відкривати `index.html` подвійним кліком (протокол `file://`) недостатньо. Запустіть локальний сервер:

```
python -m http.server 8000
```
і відкрийте http://localhost:8000/

## Безпека
Сайт без серверної частини: секретних ключів у коді немає, користувацькі дані виводяться через `textContent` або екрануються, замовлення та профіль зберігаються лише в `localStorage` браузера.

# Зображення

Усі картинки вже лежать у цій папці, завантажувати нічого не треба:

- `logo.png` — логотип у шапці й підвалі
- `hero-bg.webp` — фон першого екрана головної
- `cat-*.webp` — 7 категорій на головній
- `product-*.webp` — 4 товари (головна, каталог, кошик, сторінка товару)
- `about-hero.webp` — фото на сторінці «Про нас» (поки той самий знімок майстерні; можна замінити своїм, зберігши назву)

Щоб замінити картинку, збережіть нову з такою самою назвою (`.webp`) у цю папку.

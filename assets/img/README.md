# Зображення

Усі картинки вже лежать у цій папці, завантажувати нічого не треба:

- `logo.png` — логотип у шапці й підвалі
- `hero-bg.png` — фон першого екрана головної
- `cat-*.png` — 7 категорій на головній
- `product-*.png` — 4 товари (головна, каталог, кошик, сторінка товару)
- `about-hero.png` — фото на сторінці «Про нас» (поки той самий знімок майстерні; можна замінити своїм, зберігши назву)

Щоб замінити картинку, збережіть нову з такою самою назвою (`.png`) у цю папку.
